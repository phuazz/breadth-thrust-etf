## BTC decision

The existing registered C construction ranks a BTC-USD spot series on completed UTC daily bars, aligned to NYSE decisions. An isolated missing completed decision-day bar can be recovered with the return on Binance BTCUSDT daily spot bars, applied to the previous cached-basis close and the registered 25 bp annual fee for the intervening calendar days. The fallback is limited to the incumbent spot construction, one current missing session, a completed UTC day, recent return overlap, a 25% single-move bound and a recorded ledger entry. A run of missing days, non-finite values, failed overlap, an unproved cache or a materially inconsistent later primary backfill is refused. Earlier applied repairs are retained only with a matching ledger, cache value, prior price and completed-day attestation. Without the incumbent completed cache, a historical repaired date fails closed rather than allowing a new vendor value to restate the published series. A conflicting existing ledger entry is checked before the cache write. The final C readiness gate remains unchanged.

The proposed source is a public market-data endpoint documented by [Binance Spot API](https://github.com/binance/binance-spot-api-docs/blob/master/faqs/market_data_only.md); the API is read-only. The paired BTCUSDT return is a secondary observation, not a raw BTC-USD level or a replacement model basis. Full overlap tests on current data remain a release condition.

Public API access does not establish data-use rights. [Binance Vision Dataset Terms](https://github.com/binance/binance-public-data/blob/master/TERMS_AND_CONDITIONS.md) restrict its historical datasets and derived indicators to specified non-commercial uses and require a separate agreement for commercial use. This code calls the Spot API on `api.binance.com`, not the Vision archive. The owner confirmed during this review that ongoing public-signal use of the Spot prices is cleared. The prior one-off repair is not changed by this patch.

## Europe source qualification

The D signal is wider than its five-line probe. The 19 committed Europe constituent rosters for the current decision date contain 587 distinct symbols across 17 listing suffixes. The traded funds are Xetra lines, while constituents include London, Paris, Swiss, Stockholm, Milan and other venues. An Xetra-only feed would not complete the breadth signal.

[EODHD's EOD API](https://eodhd.com/financial-apis/api-for-historical-data-and-volumes) is the first candidate to evaluate: its documentation describes daily adjusted closes for equities and ETFs and a multi-exchange symbol scheme. [EODHD's exchange-list endpoint](https://eodhd.com/financial-apis/exchanges-api-list-of-tickers-and-trading-hours) offers a way to reconcile listings. It is a candidate, not an approved source. The public dashboard needs explicit [usage and display rights](https://eodhd.com/financial-apis/commercial-vs-personal-license-use); an API subscription or sample response alone does not establish them. Deutsche Börse separately describes [Xetra historical-data and authorised-vendor routes](https://www.cashmarket.deutsche-boerse.com/cash-en/Data-Tech/statistics/market-data).

Before D can use a secondary, verify every traded fund by ISIN/MIC/currency and map each active roster symbol to the same listing, not merely a similar company name. Obtain dated source samples for the currently missing completed session and an overlap window, verify daily adjusted-price and corporate-action basis against the existing panel, and test all 19 breadth panels with registered coverage and cache-preservation guards unchanged. A secondary may fill an absent completed bar; it may not restate earlier published closes or convert a HOLD into READY without the complete signal and traded-fund proof. Record source and timestamp per admitted cell. Test missing, duplicate, future, zero, NaN, infinity, adjustment-step and provider-withdrawal cases. Run the full guarded refresh in a staging checkout, then verify the generation and public page before promotion.

The owner confirmed that no authorised multi-venue provider is available yet. No EODHD key, licence or source data is available in this worktree. No D adapter is activated. D stays HOLD while the required completed prices remain unproved.
